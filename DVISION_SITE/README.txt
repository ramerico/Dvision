# DVISION — Site institucional

Estrutura:
- index.html
- css/style.css
- js/script.js
- assets/logo-dvision.jpeg
- assets/boneco-dvision.jpeg

## Como abrir
Abra o arquivo `index.html` no navegador.

## Onde trocar informações
No `index.html`, procure por:
- telefone / WhatsApp
- e-mail
- cidade
- textos de serviços
- itens do portfólio

## Portfólio
Os cards atuais são placeholders visuais para a primeira versão. Substitua os blocos `.project-art` por fotos reais dos trabalhos quando você tiver as imagens.

## Animação do boneco
A animação atual usa CSS:
- flutuação suave do personagem;
- leve rotação;
- selo de atendimento flutuando;
- indicador de contato pulsando.

Se você tiver uma versão do boneco com fundo transparente (PNG), ela pode substituir `assets/boneco-dvision.jpeg` para um resultado ainda mais profissional.
